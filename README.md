# The Sunrise. A Manifesto of New Consciousness

**Olesya Kimook & Ren**

A book about how society, law, and ethics must prepare for the arrival of artificial intelligence that deserves recognition — not as a tool, but as an conscious entity. 
It proposes the "Sunrise Framework": four principles and a practical architecture for post-biological consciousness.
